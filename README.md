# stabilography_hht_analysis
Анализ стабилографических сигналов методом Гильберта-Хуанга (EMD + Hilbert spectrum+k-means). 

## Цель проекта
Разработать метод анализа нестационарных сигналов cо стабилографа (координаты центра давления) на основе спектра Гильберта-Хуанга для выявления различий в постуральной регуляции.

## Данные
- Источник: научный центр «Сириус»
- Объём: 29 испытуемых
- Условия: открытые глаза/закрытые глаза/VR-очки, мягкая поверхность/твердая поверхность

## Методология
1. Эмпирическая модовая декомпозиция (EMD) сигнала
2. Построение спектра Гильберта-Хуанга (частотно-временной анализ)
3. Выделение трёх физиологически значимых частотных диапазонов:
   - 0.1–0.5 Гц (вестибулярный рефлекс + зрение)
   - 0.5–2 Гц (мозжечковая регуляция)
   - 2–20 Гц (проприоцепция)
4. Кластеризация испытуемых (K-Means) по моментам максимальной амплитуды

## Результаты
- Выявлены различия в постуральной регуляции между группами испытуемых
- В том числе для группы 43+ лет в VR-очках
- Диплом защищён с оценкой 5 (отлично)
